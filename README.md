# VelocityCRM

Uniwersalna, konfigurowalna platforma do zarządzania relacjami i procesami biznesowymi — jedno
źródło kodu dla aplikacji webowej, desktopowej (Windows, macOS, Linux) i mobilnej (Android, iOS).

A universal, configurable platform for managing business relationships and processes — one
codebase for the web, desktop (Windows, macOS, Linux) and mobile (Android, iOS) applications.

## Stos technologiczny / Technology stack

Vue 3 · TypeScript · Tailwind CSS · Pinia · Vue Router · vue-i18n · Vite · Tauri 2 · Vitest ·
Playwright

## Szybki start / Quick start

```bash
npm install
npm run dev
```

Aplikacja uruchomi się pod adresem `http://localhost:1420`.
The application starts at `http://localhost:1420`.

## Główne cechy / Highlights

- Jeden kod dla web, desktop i mobile (Vue + Tauri).
- Konfigurowalne profile branżowe (sprzedaż, nieruchomości, ochrona zdrowia, edukacja,
  hotelarstwo, usługi prawne) zmieniające terminologię i etapy procesu bez zmiany kodu.
- Pełna responsywność (RWD) i zgodność z wytycznymi WCAG 2.1 AA.
- Dwujęzyczny interfejs (polski / angielski).
- Testy jednostkowe, dostępności i end-to-end.

- One codebase for web, desktop and mobile (Vue + Tauri).
- Configurable industry profiles (sales, real estate, healthcare, education, hospitality, legal
  services) that change terminology and pipeline stages without touching the code.
- Fully responsive (RWD) and aligned with WCAG 2.1 AA guidelines.
- Bilingual interface (Polish / English).
- Unit, accessibility and end-to-end tests.
