# Tłumaczenia i lokalizacja

## Język interfejsu a profil branżowy

W aplikacji istnieją dwie niezależne warstwy językowe:

1. **Język interfejsu** (`vue-i18n`) — teksty przycisków, nagłówków, komunikatów. Przełącznik
   znajduje się w nagłówku aplikacji oraz w Ustawieniach. Obsługiwane języki: polski (`pl`,
   domyślny) i angielski (`en`).
2. **Terminologia branżowa** (`src/config/industries.ts`) — nazwy encji takich jak „kontakt” czy
   „szansa sprzedaży”, zależne od wybranego profilu branżowego. Terminologia jest tłumaczona
   niezależnie dla obu języków interfejsu.

Zmiana języka interfejsu nie zmienia profilu branżowego i odwrotnie — obie warstwy współpracują
ze sobą w komponentach przez funkcję kompozycyjną `useIndustryLabels`.

## Pliki tłumaczeń

- `src/locales/pl.json` — teksty polskie.
- `src/locales/en.json` — teksty angielskie.

Oba pliki muszą mieć identyczny zestaw kluczy (zagnieżdżonych). Test
`tests/unit/i18n/locale-parity.spec.ts` sprawdza to automatycznie przy każdym uruchomieniu testów.

## Dodawanie nowego tekstu

1. Dodaj klucz do `src/locales/pl.json` oraz dokładnie ten sam klucz do `src/locales/en.json`.
2. Użyj go w komponencie przez `t('sekcja.klucz')` (funkcja `t` z `useI18n()`).
3. Jeśli tekst zależy od terminologii branżowej, przekaż odpowiednią wartość jako parametr,
   np. `t('contacts.title', { plural: contactPlural })`.
4. Uruchom `npm run test`, aby upewnić się, że oba pliki tłumaczeń pozostały zsynchronizowane.

## Dodawanie kolejnego języka interfejsu

1. Utwórz nowy plik, np. `src/locales/de.json`, z identycznym zestawem kluczy jak `pl.json`.
2. Zarejestruj język w `src/i18n/index.ts` (obiekt `messages`).
3. Dodaj opcję w `src/components/common/LocaleSwitcher.vue`.
4. Rozszerz typ `SupportedLocale` oraz logikę wyboru w `useIndustryLabels`, jeśli terminologia
   branżowa ma również obsługiwać nowy język.

## Formatowanie dat, liczb i walut

Formatowanie zależne od języka znajduje się w `src/utils/format.ts` i korzysta z wbudowanego w
przeglądarkę API `Intl` (`Intl.NumberFormat`, `Intl.DateTimeFormat`, `Intl.RelativeTimeFormat`) —
nie wymaga dodatkowych bibliotek i automatycznie wspiera nowe języki dodane do `Intl`.
